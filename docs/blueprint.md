# **App Name**: GO!Culture

## Core Features:

- Firebase Authentication: Secure user authentication via email, Google, or social media logins using Firebase.
- Interactive Map: Display cultural points of interest on an interactive map using the Google Maps API.
- Cultural Point Database: Store cultural point information including name, description, image, location, and type in Firestore.
- Proximity Detection: Unlock capture when the user is within 30 meters of a cultural point via GPS.
- Collection System: Reward users with badges and level increases as they explore and capture cultural points.
- Admin Panel: Provide a restricted admin panel for cultural managers to create and edit cultural points.
- Social Feed: Allow users to share their discoveries and comment on cultural points.
- Photo Validation: Allow users to upload a photo for location validation and to identify problems in that location.

## Style Guidelines:

- Primary color: A vibrant purple (#9D53F5), evoking creativity and exploration. It creates an atmosphere of adventure and discovery.
- Background color: A light lavender (#F2E7FF) background, subtly desaturated from the primary purple, ensures content legibility and visual comfort.
- Accent color: A lively pink (#F553A4) complements the primary color. Its increased brightness and saturation highlights interactive elements and calls to action.
- Headline font: 'Poppins', sans-serif, for headlines and short descriptions.
- Body font: 'PT Sans', sans-serif, for body text and longer descriptions.
- Use vibrant, custom icons to represent different categories of cultural points. Use clear and recognizable symbols for badges and achievements.
- Design a responsive layout optimized for mobile devices. Utilize card-based designs for cultural points and feed items.
